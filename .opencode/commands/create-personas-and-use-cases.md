You are helping me prepare a Product Requirements Document (PRD).

PRD File: `../docs/prd.md`

Product idea: `../docs/idea.md`

Known requirments: `../docs/requirements.md`

Inside the PRD file create 3 user personas. For each persona, include:
- goal
- frustration
- main use cases
- success condition

Keep the wording simple and practical. Do not invent technical implementation details

# Example:
Persona | Example
---|---
Name or role | Project manager
Goal | Assign work and know what is delayed
Frustration | Tasks are scattered across messages and notebooks.
Main use cases | Create project, assign task, review task status, follow up on overdue work
Success condition | Can see all active work without asking every team member
